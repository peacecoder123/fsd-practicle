# Full Stack Development Practicals

15 independent college practical projects covering HTML, CSS, JavaScript, React, Node.js and Express.js.

## Technologies

- HTML5, CSS3, JavaScript
- React.js (Vite)
- Node.js
- Express.js

## Running HTML Practicals (01–06)

Open `index.html` in a browser.

## Running React Practicals (07–10)

```bash
cd Practical-0X-Name
npm install
npm run dev
```

## Running Node.js Practicals (11–13)

```bash
cd Practical-1X-Name

node app.js
```
